# CLI Tortoises: playable demo

Ride a tortoise around a sea of turtle islands, battle and tame the wild ones, play the Shell Duel card game
and command the Wartles war table. It runs in the browser on a phone or a computer: open the site and press
**Play free**. There's nothing to install and no wallet to connect.

- `index.html` is the landing page, and `game.html` is the game. `wartles/` is the war table's own page (Wartles &
  Wartoises), the one its clips send people to.
- Your progress stays in this browser.

Built from a private source repository; this repo holds the published build only. All rights reserved unless stated in LICENSE.

The game's own code here is obfuscated; three.js and the other libraries ship as they are.
